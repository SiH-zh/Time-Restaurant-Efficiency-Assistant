# 时光餐厅 · 餐厅效率助手

自由调整雇员上限、顾客到店间隔和用餐速度，扩展乐队小费容量，并定时自动收取小费。

**当前正式版本：1.0.0。推荐通过[创意工坊订阅安装](https://steamcommunity.com/sharedfiles/filedetails/?id=3839577523)。**

所有功能独立开关，首次安装默认全部关闭；之后自动保存你的选择。模组独立运行，不依赖“日常助手”或“餐厅管家”。

## 推荐安装：创意工坊

1. 打开[餐厅效率助手创意工坊页面](https://steamcommunity.com/sharedfiles/filedetails/?id=3839577523)，点击“订阅”。
2. 等待下载完成，在游戏主菜单的“模组”中启用“餐厅效率助手”，按游戏提示确认代码模组。
3. 完全退出并重新启动游戏，进入自己的餐厅。
4. 点击右上角的餐厅门面图标，设置参数，再开启需要的功能。

入口会自动避让已有模组按钮，与其他入口共同排列，不固定左右顺序。关闭设置面板不会关闭已开启的功能。

## 功能一览

| 功能 | 调整范围与使用方式 |
|---|---|
| 雇员总上限 | 1—50人的整数，不含保安；提供10、20、30、40、50人预设 |
| 顾客到店间隔 | 0.1—10.0秒/人，步长0.1秒；提供每5秒、每2秒、每1秒一人预设 |
| 到店悬浮调整 | 支持开关、滑块、输入和快捷按钮；拖动标题移动，自动保存位置 |
| 顾客用餐速度 | 1.0—20.0倍，步长0.1；可选择同步加速包房用餐 |
| 乐队小费容量 | 每位乐手2000—100000笔；滑块每格100笔，也可输入整数；提供2000、5000、1万、10万笔预设 |
| 自动收取小费 | 每隔5—3600秒尝试一次，提供30秒和60秒预设，沿用原版结算规则 |

### 雇员扩容

修改的是招聘上限，不会直接生成员工。调整后仍通过原版人才市场招聘，工资、招聘费用、体力、雇期和保安限制沿用原版。降低上限或关闭功能不会自动解雇已有员工，只会限制新增招聘。

### 到店与用餐

到店数值越小，目标补客速度越快。0.1秒表示目标每秒10人，10秒表示目标每10秒1人。实际客流仍受空座、入口、库存、帧率和原版营业逻辑限制；开业预填充、特殊顾客及包房来客周期不属于此项范围。

点击“经营效率”页的“悬浮调整”，可收起主面板，边经营边调整到店间隔。主面板与悬浮窗同步开关和数值；关闭主面板后，已打开的悬浮窗仍可继续使用。

用餐倍率只调整上菜后的吃饭阶段，不改变移动、点菜、烹饪、上菜、结账及包房离场冷却。已有等待或用餐通常从下一轮开始使用新设置。

### 乐队小费

容量按每位乐手分别计算。首次安装的容量选值为10万笔，开启容量功能后才生效。

自动收取按真实时间计时，仅在游戏运行且位于自己的餐厅时检查。离开餐厅、做客、切换存档或修改间隔后重新计时，不补跑遗漏周期。达到原版收取门槛才结算，门槛与单价沿用游戏配置，不额外生成金币。面板显示倒计时及最近一次结果，成功收取后立即保存。

## 设置与卸载

- 首次安装全部功能关闭，包房同步加速关闭，悬浮窗默认不打开。
- 后续启动和升级保留开关、参数及悬浮位置，不会每次重置。
- 设置保存在当前用户数据目录的 `RestaurantBoost/settings.json` 中，与模组程序分离，不需要随更新覆盖。
- **彻底停用或卸载前，请先收取超过原版容量上限的小费。**模组保持加载时会保护现有超额存量；停用后，原版读档可能按基础上限截断。
- 从手动版或本地测试版切换到工坊版时，避免同时启用两份副本。切换前如有超额小费，先收取后再停用旧副本。

## 备用安装：手动安装

仅在不方便使用创意工坊时，前往[发行版下载页](https://github.com/SiH-zh/Time-Restaurant-Efficiency-Assistant/releases/latest)下载1.0.0安装包。请勿把下载的压缩包直接放进模组目录。

1. 完全退出游戏并解压安装包。
2. 将 `RestaurantBoost` 整个文件夹复制到游戏安装目录的 `Mods` 文件夹中，确认目录为 `Mods/RestaurantBoost/info.ini`，避免多套一层文件夹。
3. 启动游戏，在“模组”中启用“餐厅效率助手”，重启后使用。

也可以运行项目内的安装脚本，按实际安装位置传入目录：

```powershell
& '.\安装.ps1' -GameRoot 'D:\SteamLibrary\steamapps\common\时光餐厅'
```

脚本会先备份已有同名模组，保留其非零工坊作品编号。普通使用者无需修改作品编号或执行上传。

## 兼容性与验证

针对《时光餐厅》2.0.0、2026年11月11日编译版本验证，与“日常助手”1.2.1及“餐厅管家”1.1.2共同完成实机检查。其他模组若修改相同的招聘、补客、用餐或小费逻辑，可能相互影响。游戏后续更新可能需要适配。

375项规则验证通过。实机验证范围及尚未覆盖的情况见[验证报告](验证报告.md)。本模组不修改官方程序集，不包含游戏官方程序集、存档或账户数据。

## 从源码编译

需要本机已安装游戏，以及系统自带的编译器。编译时直接引用本机游戏的托管程序集，不分发游戏依赖：

```powershell
& '.\RestaurantBoost\Source\编译.ps1' -GameRoot 'D:\SteamLibrary\steamapps\common\时光餐厅'
```

输出为 `RestaurantBoost/RestaurantBoost.dll`。更新程序后请完全退出并重新启动游戏。

运行独立规则验证：

```powershell
& '.\验证\运行规则验证.ps1'
```

主要源码如下：

| 文件 | 作用 |
|---|---|
| `Rules.cs` | 参数解析、范围、默认值及收取定时规则 |
| `Patches.cs` | 雇员上限、到店和用餐补丁 |
| `BandPatches.cs` | 小费容量、存量保护和读档补丁 |
| `BoostView.cs` | 设置面板与悬浮调整界面 |
| `ArrivalWindowDrag.cs` | 悬浮窗拖动、位置保存与边界限制 |
| `ModBehaviour.cs` | 模组生命周期、入口、设置与自动收取 |
